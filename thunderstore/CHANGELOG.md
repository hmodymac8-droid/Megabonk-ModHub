## 1.2.6

- Suggest or request: a "Suggest" button (Installed mods) and "Request a mod" (Get mods) open a short form; "Send on GitHub" opens a filled-in GitHub issue in your browser. Nothing is sent from the game.
- Clicks on Mod Hub no longer press game buttons behind it.
- Missing requirements: a mod from Downloads or the drop folder that needs other mods says so, with "Install them".
- Game updated? Mod Hub says so once and offers updates or vanilla mode.
- Possible clashes: mods that change the same game function in a risky way are marked.
- Copy report: everything a helper needs (mods, versions, clashes, history, errors), without personal details.
- 8 themes (Theme button at the top).

## 1.2.5

- Put back: Remove lines in History get a button that restores the mod where it was.
- A mod that came along as a requirement says so: "needed by X" in Installed mods and in History.
- Removing a mod can take the mods that came with it along; modpacks install without an error.
- Opening Mod Hub and switching mods is faster: each mod file is read once until it changes.

## 1.2.4

- History: a new page on the Installed mods tab lists what Mod Hub did (installs, updates, removals, switches, profiles), with a Copy button for help requests.
- Profiles now switch custom characters on and off too.
- A switch that fails (a file in use) now says so instead of looking like it worked.

## 1.2.3

- What's new: after a mod updates, Mod Hub opens when the game starts and shows the author's notes for the new version (or says none were published, with a link to the mod's page). Mod rows also get a What's new button.
- Thunderstore edition: Thunderstore only, updated by your mod manager.
