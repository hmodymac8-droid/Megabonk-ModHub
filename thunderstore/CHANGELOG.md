## 1.2.4

- History: a new page on the Installed mods tab lists what Mod Hub did (installs, updates, removals, switches, profiles), with a Copy button for help requests.
- Profiles now switch custom characters on and off too.
- A switch that fails (a file in use) now says so instead of looking like it worked.

## 1.2.3

- What's new: after a mod updates, Mod Hub opens when the game starts and shows the author's notes for the new version (or says none were published, with a link to the mod's page). Mod rows also get a What's new button.
- Thunderstore edition: Thunderstore only, updated by your mod manager.
