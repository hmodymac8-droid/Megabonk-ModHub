# Mod Hub

An in-game mod manager for Megabonk. Press **F4** (or **L3 + R3** on a controller) to open it.

- **Installed mods:** switch any mod ON or OFF, remove it, or go back to the version you had before an update.
- **Get mods:** browse Thunderstore mods and install or update them in one click, right in the game.
- **What's new:** after a mod updates, Mod Hub shows the author's notes for the new version when the game starts.
- **Profiles & friends:** save sets of mods and share them with a code.
- **Crash safety:** if the game stops starting after a change, Mod Hub offers to turn off (or roll back) what's new.
- **MelonLoader mods** from Thunderstore run through the included Melon Bridge.
- English and Arabic.

Mod Hub itself is updated by your mod manager (r2modman or Gale). Changes to mods apply when the game restarts; nothing is ever deleted (removed mods go to `BepInEx\_hub_removed`).
